# Networking Quiz

A static mobile-friendly quiz using the 55 questions in the supplied PDFs. Original answer keys are preserved (including source inconsistencies).

## Publish to GitHub Pages

1. Create a new **public** GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, `questions.js`, and optionally `questions.json` and `README.md` to the repository root.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, set **main** and **/(root)**, then save.
4. Visit the URL GitHub Pages displays after deployment.

Open `index.html` locally to use without a server. Wrong-answer history is stored only in your browser.

Note: Q10 in PDF 1 marks choice B for TIA, although the common industry expansion is Telecommunications Industry Association. The website deliberately retains source answers.
